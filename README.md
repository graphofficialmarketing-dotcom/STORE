# บอร์ดโปรโมชั่นประจำสาขา (เวอร์ชัน Vercel)

- **หน้าร้าน:** `https://<ชื่อโปรเจกต์>.vercel.app/` (ต่อท้าย `#cafe`, `#masando` ฯลฯ เพื่อเปิดสาขานั้น)
- **หน้าเพิ่มข้อมูล (ทีมการตลาด):** `https://<ชื่อโปรเจกต์>.vercel.app/#marketing` (ต้องใส่รหัสผ่าน)

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บทั้งหมด (หน้าร้าน + หน้าการตลาด) และข้อมูลตั้งต้น |
| `api/data.js` | API อ่าน/บันทึกข้อมูลลงฐานข้อมูล ตรวจรหัสผ่าน |
| `package.json` | ไฟล์ตั้งค่าโปรเจกต์ |

## ตั้งค่าครั้งแรก

1. **อัปไฟล์ขึ้น GitHub** — อัปโหลด `index.html`, `package.json`, `README.md` และโฟลเดอร์ `api` (ที่มี `data.js` อยู่ข้างใน) เข้า repository ที่เชื่อมกับ Vercel ไว้ แล้วกด Commit changes
2. **สร้างฐานข้อมูล** — ใน Vercel เข้าโปรเจกต์ → แท็บ **Storage** → **Create Database** → เลือก **Upstash for Redis** (แพ็กเกจฟรี) → เลือกภูมิภาคใกล้ไทย เช่น Singapore → กด Connect กับโปรเจกต์นี้
   Vercel จะใส่ตัวแปร `KV_REST_API_URL` และ `KV_REST_API_TOKEN` ให้เอง
3. **ตั้งรหัสผ่านทีมการตลาด** — **Settings** → **Environment Variables** → เพิ่ม
   - Key: `ADMIN_PASSWORD`
   - Value: รหัสผ่านที่ต้องการ (ยาวอย่างน้อย 10 ตัว ไม่ใช้ซ้ำกับรหัสอื่น)
   - ติ๊กทุก Environment แล้วกด Save
4. **Deploy ใหม่** — แท็บ **Deployments** → กด ⋯ ที่อันล่าสุด → **Redeploy** (ตัวแปรใหม่จะมีผลหลัง deploy ใหม่)
5. **ทดสอบ** — เปิด `/#marketing` ใส่รหัสผ่าน ลองเพิ่มงานแจกกาแฟ 1 รายการ แล้วเปิดหน้าร้าน `/#catering` ดูว่าขึ้นหรือไม่

## การทำงาน

- ครั้งแรกที่ฐานข้อมูลยังว่าง หน้าเว็บจะใช้ข้อมูลตั้งต้นใน `index.html` เมื่อทีมการตลาดกดบันทึกครั้งแรก ข้อมูลจะถูกเก็บลงฐานข้อมูล และหลังจากนั้นจะใช้ข้อมูลจากฐานข้อมูลเสมอ
- หน้าร้านดึงข้อมูลใหม่เองทุก 3 นาที เปิดจอทิ้งไว้ได้
- ถ้าสองคนแก้พร้อมกัน คนที่บันทึกทีหลังจะได้ข้อความให้ทำรายการอีกครั้งบนข้อมูลล่าสุด ข้อมูลของอีกคนจะไม่ถูกเขียนทับ
- รหัสผ่านถูกตรวจที่เซิร์ฟเวอร์ ไม่ได้อยู่ในหน้าเว็บ เปลี่ยนรหัสได้ที่ Environment Variables แล้ว Redeploy

## ข้อควรรู้

- ใครมีลิงก์ก็เปิดหน้าร้านได้ รวมถึงข้อมูลที่กรอก เช่น ชื่อและเบอร์ผู้ประสานงาน อย่ากรอกข้อมูลที่ไม่อยากให้คนนอกเห็น
- ข้อมูลที่เพิ่มผ่านเว็บอยู่ในฐานข้อมูล ไม่ได้อยู่ในไฟล์ `index.html` ถ้าแก้ข้อมูลตั้งต้นในไฟล์ภายหลังจะไม่มีผล หลังจากเคยบันทึกครั้งแรกแล้ว
